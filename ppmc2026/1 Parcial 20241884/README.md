# Reto 06 — Energía: mesetas de consumo alto

Programa desarrollado en **lenguaje C** para la asignatura **Programación para Mecatrónicos**.

El proyecto analiza una matriz de valores para detectar eventos, calcular impactos y rachas consecutivas, y determinar la fila de prioridad y la columna destacada, respetando las condiciones establecidas en el enunciado.

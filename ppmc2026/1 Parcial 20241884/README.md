# Reto 06 — Energía: mesetas de consumo alto

Programa desarrollado en **lenguaje C** para la asignatura **Programación para Mecatrónicos**.

El Reto 06 — Energía: mesetas de consumo alto consiste en desarrollar un programa en lenguaje C que analiza una matriz de valores enteros para identificar eventos de consumo según un límite de diferencia y un umbral establecidos. A partir de estos datos, el programa calcula la cantidad de eventos por fila, su impacto acumulado y las rachas consecutivas, incluyendo la longitud de la racha más larga y su posición inicial.

Además, el programa determina la fila de prioridad mediante criterios de comparación y selecciona la columna con mayor cantidad de eventos. También valida las dimensiones, los parámetros y los valores de entrada para garantizar el cumplimiento de las restricciones del enunciado. Este proyecto permite aplicar conceptos fundamentales de programación en C, como matrices, ciclos, condicionales, contadores, acumuladores y validación de datos.
